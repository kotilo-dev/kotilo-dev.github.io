Kotilo Shells. Your whole desktop, keyboard first.

Bars, launchers and control centres for tiling window managers on Windows and Linux. Each shell is free, open source and installs on top of the window manager you already run.

Kotilo Zebar Pack

A top bar for GlazeWM with a dynamic island in the middle. The island shows what is going on (media, timers, notifications) and opens into a control centre, an app launcher and a set of panels, without leaving the keyboard.

  • Control centre: Wi-Fi, sound and Bluetooth, volume and brightness, CPU, RAM and battery, weather, next calendar event and media controls.
  • Launcher for apps, windows, system and GlazeWM commands, Settings pages and recent files, with a calculator, emoji, web search and clipboard history.
  • Windows notifications live in the island, plus panels for calendar, to-do, notes, timer and Pomodoro, news feeds and the system tray.
  • GlazeWM workspaces, tiling direction and window list in the bar; shortcuts editable in Settings.
  • 17 themes with matching GlazeWM window borders and a wallpaper picker. No account, no analytics.
