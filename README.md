# kotilo.dev

Source of the [Kotilo](https://github.com/kotilo-dev/kotilo) website, served by GitHub Pages at https://kotilo.dev.

Plain HTML and CSS, no build step. Colors and type follow the app's `DESIGN_SYSTEM.md`; screenshots come from the app's end-to-end tests (`docs/images`). Fonts: Geist and Geist Mono, SIL Open Font License (`assets/fonts/OFL.txt`).

Content is licensed under the Apache License 2.0, like the app.
