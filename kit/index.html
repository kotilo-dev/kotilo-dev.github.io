How it works

Clipboard to result in two keystrokes

Copy a JWT, press Ctrl+Shift+K (Cmd+Shift+K on macOS), hit Enter: the decoded payload is on your clipboard.

Palette from anywhere

A global shortcut opens the palette. Tools that recognize your clipboard appear under Suggested; Enter runs one and copies the result.

Full window

Every tool in a sidebar with live input and output. Ctrl+K searches; pasting recognized content into the search opens the matching tool.

Keyboard all the way

Tab shows options, Alt+letter switches one, Ctrl+1…9 runs a row, Ctrl+Enter opens the tool in the full window.

Dev themes

Catppuccin, Gruvbox, Tokyo Night, Everforest, Nord, Rosé Pine and Dracula, each with a light pair. Follows system light/dark; import .toml themes.

Private by design

No network calls and no telemetry. Clipboard detection asks for consent on first launch, and clipboard content is never stored.

English and Turkish

Interface and error messages in both. Turkish case conversion (İ/ı) and sorting follow tr-TR rules.

Command line

The same tools in your shell

Every tool also runs from the terminal, reading standard input. Bare words select options, --json prints the result with metadata, and detect tells you which tool fits an input.

echo 1700000000 | kotilo kit timestamp --tz Europe/Istanbul
echo '*/15 9-17 * * 1-5' | kotilo kit cron
pbpaste | kotilo kit detect

The CLI is a single Node.js file attached to each release.
