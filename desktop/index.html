Run your AI coding agents side by side. See which one needs you.

Claude Code, Codex, Copilot, Gemini and more in real terminals. Kotilo shows which agent is working and which one is waiting, lets you answer permission requests in one click, and keeps track of what it all costs.

Agents and terminals

Real terminals
Tabs and split panes with ConPTY shells, agent CLIs and your own commands. Clickable file:line links, file tree and diffs.
Permission card
The tool, the command or file and a risk label. Allow once, always allow or deny with one click, or answer in the terminal.
Mission control
Every running agent on one screen, with a timeline of what each session did and the files it changed.
Agent context new
The instruction files, rules, skills and MCP servers an agent picks up in a workspace, with a rough token count. MCP secrets are never shown.

Parallel work and review

Worktrees new
Give each agent its own git worktree and branch, compare what it changed, then merge or remove it. Works with every supported agent.
Review notes
Comment on lines of a diff and hand every note, with file, lines and code, to an agent as one prompt.
Docs check new
Finds paths your docs and AGENTS.md name that no longer exist, and docs whose code changed since. Also as kotilo-docs check for CI.
Sessions and resume
Every agent session of the last 90 days with model, project, tokens and cost. Resume one in its folder with the agent's own resume command.

Usage and cost

Usage, cost and limits
Tokens and estimated cost by day, week, 5-hour block, project, model and agent. Plan limits where the agent reports them. CSV and Excel export.
In the tray new
Today's tokens and cost, the active 5-hour block, your plan limits and the agents waiting for you, one click from the tray icon.
Unseen work stays marked
Finished work you have not looked at keeps a count on the taskbar icon, and you get one "while you were away" summary when you come back.

Around the terminal

Composer and tasks
Longer prompts with file mentions and saved prompts. A personal task list, daily summaries and wait-time reports.
Quick commands
The shell commands and prompts you use every day, per workspace or for all, one click away.
Local dictation
Push-to-talk speech-to-text with Whisper, running entirely on your machine.
Themes and a snail
28 themes for the whole app and its terminals, Windows Terminal schemes import, and an optional robot snail on the taskbar that takes you to the agent that needs you.
Kotilo Deck
Your agents and their permission requests on a second screen with Kotilo Deck; approve or deny from there.

Privacy. Nothing to sign up for.

Kotilo does not wrap or replace your agents and has no server of its own.

No telemetry
No analytics, crash reports or tracking of any kind.
No transcript content at rest
Prompts and responses are never written to Kotilo's database or logs; only counts and metadata.
Agent credentials stay untouched
Kotilo does not read, copy, store or send any agent's login or token files.
Your config files stay yours
Hooks are installed only when you ask, backup-first, and only Kotilo's own entries are changed.
Local data
Settings, usage, tasks and reports live in local folders; AI provider keys in Windows Credential Manager.
Few, optional connections
Update check (can be turned off), Whisper model download when you pick one, and AI providers you configure.

Full details: privacy policy.

Download. Free, no account.

Windows: per-user installer, no administrator rights needed. Requires Windows 11 and the WebView2 Runtime (installed automatically if missing). Updates arrive automatically from GitHub Releases.

Windows x64 Windows ARM64

Linux (x64): .deb for Debian and Ubuntu, .rpm for Fedora and openSUSE, or an AppImage for any distribution with WebKitGTK 4.1. Dictation, the mascot and global hotkeys are not on Linux yet.

.deb .rpm AppImage

macOS (preview): macOS 14 Sonoma or later. Open the .dmg and drag Kotilo to Applications. Apple Silicon is M1 and later; About This Mac shows your chip. Dictation, the mascot, global hotkeys and the Dock badge are not on macOS yet.
