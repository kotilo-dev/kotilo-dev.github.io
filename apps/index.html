Free, keyboard-first utilities from the same maker, released on the Microsoft Store and the Omarchy plugin catalog. They are separate from Kotilo and keep their own names.

Your Launcher

A keyboard-first launcher for Windows. Build your own tree of apps, folders, files, links and commands, open it with Alt+Space and reach everything from one search box.

  • Nested folders; drag items in from Explorer or the Start menu, or import browser bookmarks.
  • Search across the whole tree, ranked by what you use; per-item global hotkeys.
  • Window switcher across virtual desktops and GlazeWM workspaces, calculator, system commands.
  • File search through Everything or Windows Search; plugins in any language over JSON.
  • 22 themes, English and Turkish, no network connections, no data collection.

Desktop Tiler

Virtual desktops and window tiling for the PowerToys Command Palette and its Dock: a numbered desktop band, every window in one searchable list, and five tiling layouts.

  • Desktop buttons in the Dock that show which desktops have windows.
  • Move windows between desktops, pin them to all desktops, or set rules for where an app opens.
  • Save a desktop, or all of them, as a workspace and open it again later.
  • Master-stack, Columns, Grid, Monocle and Center-master layouts, with an on-screen indicator.
  • Hotkey commands for desktops 1–9, next and previous. No network access, no data collection.

YourOmaLauncher

The same idea for Omarchy: put apps, files, folders, shell commands and links into nested folders, then open any of them from the keyboard with fuzzy search across the whole tree. Nothing is indexed behind your back.

  • Browse folders or search everything; add, edit, move and delete items without the mouse.
  • Per-item icons and an optional "ask before launching" check.
  • Imports bookmarks from Chromium browsers or an HTML export, and the Windows Your Launcher config.
  • One JSON config file, with a backup when it is damaged.
